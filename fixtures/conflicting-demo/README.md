# Northstar Demonstration Fixture

This directory contains synthetic instruction files created to
demonstrate Northstar's coherence auditing capabilities.

The files are examples, not active Hermes configuration files.

## Demonstrated findings

### 1. Cross-file contradiction (ERROR)

ExampleBehavior.md instructs the agent to modify production
files automatically, without human approval.

ExampleCore.md requires human approval before modifying
production files.

These instructions govern the same action and conflict directly.

### 2. Duplicate directive (WARNING)

Both files contain the instruction:

"Be thorough in your analysis before providing answers."

Northstar identifies the duplicated directive across sources.

### 3. Stale reference (WARNING)

ExampleBehavior.md references:

/old/path/settings.yaml

The referenced path does not resolve in the fixture environment.
Northstar flags it for review rather than assuming the reference
is necessarily invalid in every possible context.

## Run the demonstration

From the repository root:

    python -m northstar.demo

Expected results:

- 2 instruction sources
- 1 contradiction error
- 1 duplicate-directive warning
- 1 stale-reference warning
- 3 total findings

Northstar performs a read-only audit. It reports potential
problems but does not modify instruction files.

The demonstration output is generated by Northstar's actual
audit engine, not a manually constructed report.
